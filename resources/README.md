# Recursos do bundle

- `movielens_landing` armazena os CSVs da edição em um volume gerenciado.
- `movielens_lakehouse` materializa Bronze, Silver e Gold em batch.
- `medialens_analytics` publica o painel AI/BI no SQL warehouse informado.
